# VideoGuard (`android.ezerphone.videoguard`)

חוסם צפייה בווידאו ברמת המערכת, בלי שירות נגישות. מכשיר יעד: Fanvace M36 Plus (Android 13, MediaTek, root דרך Magisk).
בנייה: GitHub Actions (`gradle assembleDebug`) ופרסום ל-Release בשם `latest`.

## איך זה עובד
1. **הסרת מפענחי וידאו** (מתג): גיבוי ושכתוב של `media_codecs*.xml` ב-vendor/odm/product/system_ext/system (בלי נגיעה באודיו וב-Encoders), ועותק מסונן של ה-APEX של swcodec שמודבק מעל המקור בכל אתחול (rc + bind mount).
2. **התקנה כאפליקציית מערכת** ב-`/system/app/VideoGuard`.
3. **Device Owner** + הגבלות (כל אחת עם מתג) + חסימת הסרה.
4. **סריקה** (מתג) בכל אתחול ובכל התקנה: מושעית כל אפליקציה שברשימת האסורות, מצהירה על `video/*`, או מצרפת ספריית מפענח. אפליקציות מערכת מדולגות אלא אם הופעל "סרוק והשעה גם אפליקציות מערכת". האכיפה נפרדת: כבויה = דיווח ליומן בלבד. אפליקציה שסומנה ידנית "מושעית" מושעית תמיד (כל עוד יש Device Owner).
5. **זיהוי חזותי** (מתג): MediaProjection רציף, זיהוי תנועה וגלילה, חלון חסימה. חל גם על אפליקציות מערכת (Chrome, YouTube מותקן מראש) חוץ מרכיבים חיוניים, ובודק כל אפליקציה גלויה — כולל חלון צף (PiP) ומסך מפוצל. לכל אפליקציה: רגילה / מותרת (פטורה מהכול, עם אפשרות להשאיר זיהוי חזותי) / מושעית.
6. **PIN** נדרש לפני ההפעלה ולכניסה להגדרות. **"בטל הכל"** משחזר ומסיר הכול.

כל פקודת root ותוצאתה נרשמות ב"יומן פקודות" (ובלוגקט עם התג `VideoGuard`).

## גיבוי ובטיחות
- גיבוי המקור ב-`/system/etc/vg/backup/<מחיצה>/` וב-`/sdcard/VideoGuard/backup/`. גיבוי קיים לעולם לא נדרס; אם הקושחה עודכנה מאז, הגיבוי הישן נשמר בשם `*.old-<זמן>`.
- לפני כתיבה נבדק שאין dm-verity פעיל על המחיצה.
- כשל בכתיבה מחזיר מיד את מה שנכתב. מנגנון "boot pending": אם האתחול אחרי שינוי לא מגיע ל-boot_completed 3 פעמים, `boot_guard.sh` עובר ל"מצב שוחזר" ומצמיד (bind mount) את המקורות — כולל של swcodec — **בכל אתחול** עד "בטל הכל". המסך הראשי מציג אזהרה. הסקריפטים רצים בדומיין `u:r:magisk:s0` (init לא מריץ סקריפט בלי seclabel). לא נבדק על המכשיר: אחרי אתחול לבדוק `dmesg | grep boot_guard` ו-`/data/vg/boot_guard.log`.
- "בטל הכל" מסיר גם את `/system/app/VideoGuard` ואת הסתרת סמל ההטלה. האפליקציה נשארת מותקנת כאפליקציה רגילה שאפשר להסיר.

## חתימה (חד-פעמי)
עדכון של אפליקציה מותקנת דורש אותו מפתח חתימה. ה-CI חותם במפתח קבוע מתוך ה-secrets של הריפו:
```
keytool -genkeypair -keystore vg.keystore -alias videoguard -keyalg RSA -keysize 4096 -validity 36500
base64 -w0 vg.keystore   # -> secret VG_KEYSTORE_B64
```
ו-secret בשם `VG_KEYSTORE_PASSWORD` (ואופציונלית `VG_KEY_ALIAS`, `VG_KEY_PASSWORD`). בלעדיהם הבנייה נחתמת במפתח debug אקראי, עם אזהרה. לשמור את `vg.keystore` במקום בטוח ולא בריפו. המעבר למפתח הקבוע מחייב התקנה מחדש אחת (קודם "בטל הכל").
- שחזור מלא מהקושחה המגובה נשאר רשת הביטחון האחרונה.

## מגבלות
- איפוס יצרן מה-recovery מוחק את `/data`: המפענחים והאפליקציה נשארים, אבל ה-appops וה-Device Owner נמחקים. האפליקציה מזהה ומציגה "ההגנה לא שלמה, נדרשת הגדרה מחדש".
- צריבת קושחה מקורית ממחשב מבטלת הכול (לא ניתן למנוע ב-MediaTek).
- מחיצה erofs או shared_blocks לא נפתחת לכתיבה: השלב נעצר ומסביר.

## לא נבדק על מכשיר (לבדוק אחרי ההתקנה)
- ה-bind mount של ה-APEX דרך ה-rc, ו-SELinux של `boot_guard.sh`.
- ספירת "מפענחי וידאו במערכת" בתהליכי המדיה של Android 13.
- שמות חבילות ושמות ספריות מפענח ברשימות הסריקה.
- ספי הזיהוי החזותי (ראה `MotionDetector`).

`legacy-magisk/` הוא המודול הישן, לא נבנה ושמור להפניה בלבד.
